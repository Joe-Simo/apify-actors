# HTTP Request: Bulk API Calls, curl Import, JSON Fields

Send GET, POST, PUT, PATCH, DELETE, HEAD or OPTIONS requests to any public API in bulk. Paste URLs or curl commands, or fill a URL template from rows. Each response becomes a dataset row with status, headers, parsed JSON or text, picked fields, optional one row per array element, and pagination by next URL, cursor or Link header.

- Store page: https://apify.com/joesimo/http-request
- Example input: [example-input.json](example-input.json)
- Example output (real rows from a test run): [example-output.json](example-output.json)
- Pricing: $2.00 per 1,000 requests that get a response. Failed and invalid requests are free.
- Safety: private, local and cloud metadata addresses are refused on every connection and redirect. Secret headers are never written to the output.

Run it with an empty input `{}` for a demo against jsonplaceholder.typicode.com.
